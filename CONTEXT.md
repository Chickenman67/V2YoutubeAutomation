# V2YoutubeAutomation

An agent-driven pipeline that researches financial topics and produces full-length animated explainer videos (The Paint Explainer style) that split cleanly into shorts.

## Language

**Segment**:
A self-contained narrative unit; one topic = one segment = one short. A video is an ordered list of segments, and each segment is independently renderable.
_Avoid_: topic, section, part, chapter

**Video**:
The full-length output of the pipeline: an ordered list of segments, joined by hero frames.
_Avoid_: episode, upload

**Short**:
The same content as a single segment, re-rendered for the vertical shorts format. A short is never a new idea, only a segment repackaged.

**Hero frame**:
The large anchor image shown between segments. The camera zooms in from the hero frame to a segment, returns to the hero frame, and offsets to the next segment.
_Avoid_: splash, cover, main image

**Segment excursion**:
The canonical camera move: open on hero frame, zoom into a segment, return to hero frame, offset to the next segment.
_Avoid_: transition, camera shot

**Topic brief**:
The input contract to production: a title plus an ordered segment outline. Generated by AI research, never typed by the user; the user supplies at most the niche or thesis.
_Avoid_: brief, prompt, idea

**Script Standard**:
The human-written rules a narration script must satisfy before production: banned words, banned openings, no triadic abstract lists, varied sentence length and openers, contractions, no markdown artifacts, non-mechanical endings. Based on `AI-Detection-Techniques.md`.
_Avoid_: style guide, tone rules
